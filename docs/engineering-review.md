# المراجعة الهندسية — دليل المسلم Offline

**تاريخ المراجعة:** 25 أغسطس 2026
**النطاق:** تطبيق React Native/Expo في فرع `expo-offline-mobile`، ومسار بناء APK في GitHub Actions. لا يغطي هذا التقرير الموقع السابق الموجود في فرع `main`.

## الخلاصة

التطبيق يعمل كمشروع Expo موحّد للويب وAndroid وiOS، مع محتوى مضمّن وتخزين حالة محلي عبر `AsyncStorage`. لا تحتوي الشفرة التشغيلية في `app/` و`components/` و`constants/` و`hooks/` و`lib/` على استدعاء شبكة أو عميل API أو Firebase أو tRPC. تم تنظيف بقايا الخادم وقاعدة البيانات من القالب، وأصبح البناء عبر GitHub ينتج **Debug APK** قابلاً للتنزيل بنجاح.

> نجاح بناء APK يتحقق من التجميع والتغليف، لكنه لا يعادل اختبارًا يدويًا على هاتف حقيقي. يلزم تثبيت artifact على جهاز Android قبل أي توزيع واسع.

## تصميم مسار APK

يحمل الملف `.github/workflows/build-android-apk.yml` أقل صلاحيات ممكنة (`contents: read`) ولا يحتاج أسرارًا أو خادمًا. يتبع المسار هذا التسلسل: تثبيت التبعيات من lockfile، التحقق من TypeScript وlint والاختبارات وExpo Doctor، تنفيذ `expo prebuild`، ثم `./gradlew assembleDebug` ورفع artifact لمدة 14 يومًا.

الـ APK الحالي موقّع تلقائيًا بمفتاح **Debug** ويصلح للاختبار والتثبيت اليدوي فقط. لا ترفع هذا الملف إلى Google Play. عند الاستعداد للتوزيع الرسمي، يجب اختيار Android application ID مملوك لك بدل القيمة الحالية `space.manus.dalil.almuslim.expo`، ثم إضافة workflow منفصل يقرأ keystore وكلمات المرور من GitHub Secrets، ولا يضع أي مفتاح ضمن المستودع.

## ملاحظات أمنية وتشغيلية

يعني شرط Offline-first أن التشغيل الطبيعي للتطبيق لا يطلب محتوى أو يحفظ بيانات المستخدم في خادم. يبقى الوصول إلى الشبكة مطلوبًا فقط لبيئة التطوير وGitHub Actions لتنزيل الاعتماديات ومكونات Gradle. كما أن حذف التطبيق يمسح حالة `AsyncStorage` المحلية؛ لا توجد نسخ احتياطية أو مزامنة بين الأجهزة عمدًا.

أظهر تدقيق الاعتماديات الإنتاجي ملاحظات انتقالية كثيرة داخل سلسلة أدوات Expo. جرى تتبع عينات من المخاطر الأعلى إلى `@expo/cli` وMetro وأدوات البناء، وليس إلى شفرة التطبيق أو حزمة تشغيلية طلبها المستخدم. لا يعتبر ذلك إثباتًا قاطعًا لعدم وجود ثغرات؛ ينبغي إعادة تشغيل التدقيق عند ترقية Expo أو قبل إصدار متجر رسمي.
