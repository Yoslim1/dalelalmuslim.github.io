# المراجعة الهندسية — دليل المسلم Offline

**تاريخ المراجعة:** 25 أغسطس 2026
**النطاق:** تطبيق React Native/Expo في فرع `expo-offline-mobile`، ومسار بناء APK في GitHub Actions. لا يغطي هذا التقرير الموقع السابق الموجود في فرع `main`.

## الخلاصة

التطبيق يعمل كمشروع Expo موحّد للويب وAndroid وiOS، مع محتوى مضمّن وتخزين حالة محلي عبر `AsyncStorage`. لا تحتوي الشفرة التشغيلية في `app/` و`components/` و`constants/` و`hooks/` و`lib/` على استدعاء شبكة أو عميل API أو Firebase أو tRPC. أظهرت المراجعة الثانية أن الـ APK السابق كان **Debug APK** لا يضم حزمة JavaScript، ولذلك يعتمد على خادم Metro غير المتاح على هاتف المستخدم؛ وهذا يفسر بقاءه في شاشة الترحيب.

> نجاح بناء APK يتحقق من التجميع والتغليف، لكنه لا يعادل اختبارًا يدويًا على هاتف حقيقي. يلزم تثبيت artifact على جهاز Android قبل أي توزيع واسع.

## تصميم مسار APK

يحمل الملف `.github/workflows/build-android-apk.yml` أقل صلاحيات ممكنة (`contents: read`) ولا يحتاج أسرارًا أو خادمًا. يتبع المسار هذا التسلسل: تثبيت التبعيات من lockfile، التحقق من TypeScript وlint والاختبارات وExpo Doctor، تنفيذ `expo prebuild`، ثم `./gradlew assembleRelease` ورفع artifact لمدة 14 يومًا. هذا المسار يضم JavaScript والمحتوى المحليين داخل APK.

الـ APK الحالي موقّع بمفتاح اختبار مولّد من مشروع Android ويصلح للتثبيت اليدوي فقط. لا ترفعه إلى Google Play. معرّف Android الحالي هو `com.yoslim.dalilalmuslim`. قبل التوزيع الرسمي، أضف keystore تملكه إلى GitHub Secrets؛ لا تضع أي مفتاح أو كلمة مرور ضمن المستودع.

## ملاحظات أمنية وتشغيلية

يعني شرط Offline-first أن التشغيل الطبيعي للتطبيق لا يطلب محتوى أو يحفظ بيانات المستخدم في خادم. يبقى الوصول إلى الشبكة مطلوبًا فقط لبيئة التطوير وGitHub Actions لتنزيل الاعتماديات ومكونات Gradle. كما أن حذف التطبيق يمسح حالة `AsyncStorage` المحلية؛ لا توجد نسخ احتياطية أو مزامنة بين الأجهزة عمدًا.

أظهر تدقيق الاعتماديات الإنتاجي ملاحظات انتقالية كثيرة داخل سلسلة أدوات Expo. جرى تتبع عينات من المخاطر الأعلى إلى `@expo/cli` وMetro وأدوات البناء، وليس إلى شفرة التطبيق أو حزمة تشغيلية طلبها المستخدم. لا يعتبر ذلك إثباتًا قاطعًا لعدم وجود ثغرات؛ ينبغي إعادة تشغيل التدقيق عند ترقية Expo أو قبل إصدار متجر رسمي.
