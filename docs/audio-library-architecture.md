# بنية مكتبة التلاوات الاختيارية

## القرار المعماري

لن تحمل حزمة التطبيق ملفات MP3. ستكون المكتبة الصوتية في مستودع مستقل، ويختار المستخدم القارئ ثم السورة قبل تنزيلها. بعد التحقق من البصمة وحفظ الملف في مساحة التطبيق، يعمل التشغيل دون إنترنت. يظل النص القرآني وبقية الميزات محلية؛ الشبكة مطلوبة فقط لاكتشاف مكتبة الصوت ولتنزيل ما اختاره المستخدم صراحة.

بدل تخزين 6,236 ملفًا صغيرًا لكل قارئ، تعتمد المكتبة **ملفًا صوتيًا واحدًا لكل سورة مع فهرس توقيتات آيةً بآية**. يسمح العقد بإضافة انتقال إلى آية وعرض الآية النشطة مستقبلًا، بينما الإصدار الحالي يطبق تنزيل السورة وتشغيلها والتحكم الزمني. لا يقبل التطبيق ملف سورة على أنه صالح لفهرسة الآيات ما لم يرفق بتوقيتات كاملة تغطي كل آياتها.

| المكوّن | المسؤولية |
|---|---|
| `library-manifest.json` | قائمة القراء المعتمدين، الترخيص، الإصدار، وحالة النشر |
| `reciters/<id>/manifest.json` | فهرس السور وروابط التنزيل والبصمات وتوقيتات الآيات |
| `attribution.md` | نسبة المصدر والقارئ ورابط الترخيص لكل مكتبة |
| GitHub Releases | يستضيف ملفات MP3 الكبيرة في المشروع نفسه دون إدراجها في Git history |
| التطبيق | تنزيل صريح، تحقق SHA-256، تخزين محلي، تشغيل وخلفية وإدارة حذف |

## عقد التوافق آيةً بآية

```json
{
  "format": "dalil-audio-reciter/v1",
  "reciter": {
    "id": "example-reciter",
    "nameAr": "اسم القارئ",
    "license": "CC BY-SA 4.0",
    "attribution": "اسم القارئ — رابط المصدر"
  },
  "chapters": [
    {
      "chapter": 1,
      "downloadUrl": "https://github.com/OWNER/REPO/releases/download/v1/example-reciter-001.mp3",
      "sha256": "hex-digest",
      "durationMs": 77000,
      "ayahs": [
        { "ayah": 1, "startMs": 0, "endMs": 9500, "textSha256": "normalized-text-digest" }
      ]
    }
  ]
}
```

يتحقق المدقق قبل النشر من أن رقم السورة والآية موجودان في النص المحلي، وأن عدد التوقيتات يطابق عدد الآيات، وأنها مرتبة وغير متداخلة وضمن مدة الملف. عند تنزيل المستخدم، يعيد التطبيق حساب `textSha256` من النص المضمّن بعد التطبيع ثم يفحص SHA-256 لملف MP3. لا تمنح هذه الفحوص التقنية وحدها حكمًا شرعيًا أو اعتمادًا نهائيًا لجودة التجويد.

## دورة تنزيل المستخدم

عند ضغط «تنزيل التلاوة»، يعرض التطبيق القارئ والنسبة ويبدأ تنزيل الملف إلى مسار خاص بالتطبيق على Android وiOS فقط. لا يبدأ المشغل من ملف غير مكتمل أو فاشل البصمة، ويمكن للمستخدم حذف السورة المحفوظة. لا يجمع التطبيق بيانات استماع أو يرسلها إلى خادم. واجهة مؤشر تقدم وتحميل/حذف مجموعة قارئ كاملة مؤجلتان إلى مرحلة لاحقة ولا ينبغي افتراض توافرهما.

## حدود النشر والحقوق

لا يصبح القارئ «متاحًا» إلا بعد وجود ملف ترخيص قابل للمراجعة. المنشور حاليًا هو ملف تلاوة الفاتحة المرخص CC BY-SA 4.0 في إصدار `v0.1.0-pilot`، مع سبع علامات زمنية وبصمة ملف ونص؛ وهو يغطي الفاتحة فقط ولا يثبت توافر فهرس كامل أو اعتمادًا شرعيًا نهائيًا. [1] لا تُدرج تلاوات Quran Foundation أو AlQuran Cloud في المستودع ما لم يتوفر إذن إعادة توزيع صريح للملفات المحددة. [2] [3]
